In this example, a one-dimensional Stefan problem with a constant density is solved numerically using the enthalpy approach. The energy equation without the convection is solved. This numerical solution can be compared with the analtytical solution given by Ozisik, "Heat Conduction", chapter 11.3.

This example compiles [`stefan.cpp`](../stefan.cpp), shared with ex5. The integrator is selected by the integrator database in the input file.
